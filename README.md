# Server Monitor App

A lightweight server monitoring app built with **Hono.js** to manage and observe Linux systems.

## Features

- ✅ Execute Linux commands
- 📁 Browse directories
- 📄 View, delete, and download files
- ⚙️ List running services
- 📊 Monitor CPU and RAM usage

## Tech Stack

- **Backend:** Hono.js
- **Platform:** Node.js / Bun / Deno
- **System:** Linux

## Quick Start

```bash
git clone https://github.com/ramzy1453/server-monitor.git
cd server-monitor
npm install # or bun install
npm run dev  # or bun dev
```
